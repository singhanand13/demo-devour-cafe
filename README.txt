DEVOUR CAFE — UPDATED WEBSITE PREVIEW

1. Extract this ZIP completely.
2. Open index.html in your browser to view the website.
3. Keep the photos folder beside index.html so the images load.

The full editable HTML, CSS and JavaScript are included in index.html.
No installation or build command is required.

Includes responsive navigation, Instagram/Facebook icons, menu, gallery,
Friday nights, linked review excerpts, directions and ordering links.

This is an unofficial concept. The supplied images are generated mock-ups,
not photographs of Devour or its food. Confirm the final photos, business
information and content with the cafe before an official launch.
The robots.txt and page metadata request that search engines do not index it;
these do not password-protect a copy hosted elsewhere.
